`gerdoo-dyland` — a menu-bar utility that turns the MacBook notch into an interactive control centre.

**Requires macOS 14 or later on Apple silicon.** This build is arm64-only; Intel Macs are not covered by this DMG.

## What's new since 0.1.1

**Releases are now built and published by CI (#1)**

Pushing a `vX.Y.Z` tag now runs the test suite, builds the app from a clean checkout, packages the DMG, verifies the signature and architecture inside the mounted image, and publishes the GitHub release. Both previous releases were built on a developer's laptop and uploaded by hand, which meant the artifact you downloaded could not be traced back to a specific commit built in a known-clean environment. This one can: the whole run is in the Actions log.

The workflow refuses to publish a tag whose version disagrees with the app's own `MARKETING_VERSION`, so a release page can no longer claim a version the bundle contradicts.

**Every pull request is now built, tested and checked for warnings (#1)**

A CI job runs the 121 unit tests on each push and pull request, then does a clean Release build and fails if it produces a single Swift warning. The project has been warning-free since it was written; nothing enforced that until now.

**Honest note on this release:** the app itself is functionally identical to 0.1.1. Nothing in the notch, the shelf, Now Playing, the clipboard, or Quick Actions has changed. What changed is how the thing you are downloading gets made. If you are already running 0.1.1, there is no behavioural reason to update.

## Downloads

Intel Macs are still not covered. The 0.1.0 zip was a universal binary; 0.1.1 and this release are arm64-only. A universal build is a small change to the workflow whenever it is wanted.

## Before you open it

The app is **ad-hoc signed and not notarized**, so Gatekeeper will refuse to launch it the first time and show a warning about an unidentified developer. Either right-click the app and choose **Open**, or clear the quarantine flag:

```
xattr -dr com.apple.quarantine /Applications/gerdoo-dyland.app
```

Proper Developer ID signing needs an Apple Developer account and is not set up yet.

## Permissions

Only two, both optional:

- **Automation** (Music / Spotify) — asked for the first time you press play/pause/next. Without it, track metadata still appears; only the transport buttons and the progress bar stop working.
- **Login item** — only if you turn on "Launch at login".

Not requested: Accessibility, Screen Recording, Full Disk Access, Camera, Microphone, or Contacts.

## Known limitations

- **No system-wide Now Playing.** macOS exposes no public API for it — `MediaRemote` is private and, since macOS 15.4, entitlement-gated. This app integrates per player and ships Music and Spotify; anything else playing audio (a browser tab, VLC, a game) is invisible to it.
- **Drags register only once they reach the notch's catch zone.** No public API reports a drag session happening elsewhere on screen.
- **The waveform is procedural.** Reading another app's audio levels requires a system audio tap and its permission.
- **The notch stays visible over full-screen apps.**
- **The shelf is in-memory** — files stay until removed, cleared, or the app quits.
- Not sandboxed, so it cannot ship on the Mac App Store as configured.

Full detail, including the reasoning behind each constraint, is in the [README](https://github.com/ranjbar-amirabbas/gerdoo-dyland#readme).

## Performance

Idle: **0.0% CPU, ~16 MB** — including while the waveform animates.
